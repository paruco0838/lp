## 診断結果（キレイ度）一覧

回答の組み合わせで 10%〜85% のキレイ度を提示。
形式：「ご回答ありがとうございました! キレイ度XX%（絵文字）/ あなたの家のエアコンはこんな感じ（イメージ写真）」

| ルート | ペットのみ | 子供のみ | 両方 | 居ない |
|---|---|---|---|---|
| 完全分解でクリーニング済（28） | 75%😍 | 80%😍 | 75%😍 | 85%😍 |
| 通常分解でクリーニング済（29） | 50%🥺 | 60%🥺 | 50%🥺 | 60%🥺 |
| 通常分解＋年数経過（30） | 40%😖 | 45%🥺 | 35%😖 | 50%🥺 |
| 冷えが悪い（31） | 10%😱 | 10%😱 | 20%😱 | 30%😖 |
| 臭い・カビ（32） | 10%😱 | 10%😱 | 10%😱 | 20%😱 |
| 気になる事なし（100） | - | - | - | 30%😖 |

絵文字目安: 75%以上😍✨ / 50〜60%🥺 / 35〜45%😖 / 10〜30%😱

### 結果解説文のパターン（キレイ度に応じて）
- **高（75%〜）**: 「定期的なお掃除が行われているため、現状維持をオススメします。次の定期クリーニングまで問題はなさそうです。ただ、クリーニングから2年程でしたらそろそろ検討を。綺麗に拘りたい方は2年に1度、少なくとも3年に1度の分解洗浄をオススメ」
- **中（50〜60%）**: 「前回のクリーニングから2年程経ちましたらそろそろクリーニングの時期かもしれません」
- **中低（35〜50%・通常分解済）**: 「通常分解でのクリーニングの場合、奥やドレンパン部分に洗い残しが生じてしまいます。臭いが取りきれず、カビが繁殖することがあります。完全分解のクリーニングをオススメします」
- **低（10〜30%・冷えが悪い）**: 「長期間のメンテナンス不足によりかなり汚れているかも。冷えが悪い原因は室外機の汚れの可能性もある為、早めにプロによるクリーニングを。※室外機の清掃は電気代の削減にも繋がります」
- **低（10〜20%・臭い/カビ）**: 「汚れと機能低下の兆しが見られます。エアコンが汚れていると風にカビの胞子が混じり、喘息やアレルギー等の健康被害を起こしやすくなります」

### ペット・子供による追加文
- ペットあり: 「ペットを飼ってるとエアコンが汚れやすく、ペットは長時間エアコンの空気を吸い続けるため、健康を損なう事が多いです」
- 子供あり: 「子供は免疫力が低く、汚い空気を吸い続けると喘息やアレルギー症状を引き起こす可能性があり、定期的なメンテナンスが必要です」

すべての結果の最後に「・オススメのメニューを確認する✅」

## オススメメニュー（ルート別）

### 高キレイ度ルート → 通常分解洗浄（1/2/3）
- なし: 通常価格9,000円 → 24時間以内の予約で8,000円🎁
- あり: 通常価格15,500円 → 24時間以内の予約で14,000円🎁
- わからない: 両方の価格を提示（なし8,000円/あり14,000円）
- ※完全分解洗浄をご希望の場合は+1万円
- ※24時間後の通常価格は+1,000円

### 通常分解済ルート → 完全分解洗浄（53/54/55）
- なし: 通常19,000円 → 18,000円🎁（作業2~3時間）
- あり: 通常25,000円 → 24,000円🎁（作業3~4時間）
- わからない: なし18,000円/あり24,000円
- ※完全分解は任意オプション。不要なら-10,000円

### 冷えが悪いルート → ＋室外機洗浄（7/8/9）
- なし: 通常12,000円 → 11,000円🎁（作業1時間~1時間30分）
- あり: 通常18,000円 → 17,000円🎁（作業2時間~2時間30分）
- わからない: なし11,000円/あり17,000円
- 「室外機が汚れると、負荷がかかり、消費電力の増加やエアコン故障の原因にもなります」
- ※室外機洗浄は任意オプション。不要なら-3,000円

### 臭い・カビルート → ＋消臭抗菌防カビコーティング（10/11/12）
- なし: 通常12,000円 → 11,000円🎁
- あり: 通常18,000円 → 17,000円🎁
- わからない: なし11,000円/あり17,000円
- 「カビの匂い等を極力解消したい方にオススメ。徹底的に内部を綺麗にし、洗浄後も防カビコーティングで効果を持続」
- ※防カビは任意オプション。不要なら-3,000円
